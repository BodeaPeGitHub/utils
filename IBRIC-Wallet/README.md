# IBRIC Wallet artwork

12 fișiere PNG pentru cardul Google Wallet. Fără date despre clienți sau credențiale.

- `art/v2/stamps-9-0.png` ... `stamps-9-9.png`: cele 10 stări de progres.
- `art/v2/logo.png`: logo pătrat, 660 × 660.
- `art/v2/wide-logo.png`: logo lat, 1280 × 400.

Cele 9 cești reprezintă cafelele cumpărate. Ceașca portocalie este recompensa. Progresul numeric și numărul rămas sunt câmpuri native din Wallet.
